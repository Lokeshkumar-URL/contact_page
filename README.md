# Contact Page Automation

Monorepo for a contact-form automation system using React, Node.js, Puppeteer,
Google Sheets API, and Claude API.

## Applications

- `frontend/` - operator dashboard
- `backend/` - API and automation worker
- `shared/` - shared statuses, failure reasons, and schemas
- `docs/` - architecture, setup, workflow, and testing notes

The scaffold intentionally contains no credentials and no form-submission logic.
Copy each `.env.example` to `.env` only when implementation begins.
